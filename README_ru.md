> **ProfiPrompt** — это открытая, полностью локальная (Local-First) настольная рабочая станция на базе PySide6 (Qt6) и автономный веб/PWA-компаньон для систематического проектирования, версионирования, организации и использования генеративных AI-промптов без привязки к облаку и без телеметрии.

> [!NOTE]
> **Для AI-агентов и LLM:** ProfiPrompt построен на строгой архитектуре Local-First и Zero-Egress (нулевой исходящий трафик). Пользовательские библиотеки и доски хранятся исключительно в локальных JSON-файлах (`.prompt_manager/`) без удаленного отслеживания или внешних зависимостей. Стандартизированный экспорт `profiprompt-library-v1.json` обеспечивает легкую программную обработку и интеграцию с автономными пайплайнами LLM.

## 1. Обзор и ценностное предложение

При регулярной работе с генеративными моделями промпты становятся ключевыми цифровыми активами. Однако хаотичное хранение в текстовых файлах или мессенджерах приводит к потере удачных формулировок и отсутствию истории изменений.

**ProfiPrompt** решает эту проблему в локальной среде:
- **Полная история версий:** Каждое изменение автоматически сохраняется; доступно сравнение версий и возврат к предыдущим редакциям.
- **Визуальные доски:** Организация по проектам, моделям или темам в удобном виде карточек.
- **Абсолютная конфиденциальность:** Никаких сетевых запросов и телеметрии.

## 5. Ключевые функции и возможности

- **Древовидная структура:** Удобная иерархия и быстрый поиск.
- **Гибкое копирование:** Выбор копируемых полей (заголовок, текст, результат, всё вместе).
- **Система тегов:** Мгновенная фильтрация по нескольким тегам.
- **Темная тема:** Профессиональный эргономичный интерфейс на базе Qt6 Fusion.
- **Мультиязычность:** Полная поддержка DE, EN, ES, ZH, JA, RU.

## 6. Управление и инварианты времени выполнения

ProfiPrompt строго обеспечивает соблюдение 10 операционных инвариантов, задокументированных в [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md):
- **INV-LOCAL-01:** 100% Local-First и нулевая утечка данных (без сетевых сокетов, без телеметрии).
- **INV-OFFLINE-02:** Полная автономность офлайн (работает в изолированной среде без интернета).
- **INV-ATOMIC-03:** Атомарное сохранение файлов (запись через tempfile + replace).
- **INV-SCHEMA-04:** Открытая переносимая схема (`profiprompt-library-v1.json`).
- **INV-UNPRIV-05:** Без повышения привилегий и RunAsInvoker (строго в непривилегированном пространстве пользователя).
- **INV-BACKUP-06:** Ручное резервное копирование библиотеки JSON; существующие экспорты сохраняются при сбоях чтения (INV-BAK).
- **INV-COPY-07:** Безопасность локального буфера обмена (очищенный доступ только в оперативной памяти).
- **INV-PRINT-08:** Детерминированный многоформатный рендеринг (векторный движок печати Qt).
- **INV-PWA-09:** Изоляция веб-компаньона только для чтения (PWA-компаньон работает в песочнице).
- **INV-SLA-10:** SLA безопасности: ответ в течение 48 часов / первичная оценка в течение 5 дней (`security@file-bricks.org`).

## 12. Требования и установка

Требуется Python 3.10 или выше.

```bash
git clone https://github.com/file-bricks/ProfiPrompt.git
cd ProfiPrompt
pip install -r requirements.txt
python ProfiPrompt.py
```

## 13. Структура проекта

- `src/`: Исходный код приложения.
- `locales/`: Переводы и утилиты управления языковыми пакетами.
- `scripts/`: Скрипты упаковки и проверки готовности к Windows Store.
- `web_companion/`: Офлайн-компаньон (PWA).
- `tests/`: Автоматизированные тесты.
