# ProfiPrompt — Microsoft Store Listing (Русский)

## Название приложения
ProfiPrompt

## Краткое описание (макс. 100 символов)
Менеджер AI-промптов: создание, версионирование, организация на досках и экспорт.

## Описание

ProfiPrompt — профессиональный десктопный инструмент для управления, версионирования и организации AI-промптов.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:
- Управление промптами: Создание, редактирование, категоризация
- Версионирование: Полная история каждой версии промпта
- Система досок: Тематическая визуальная организация на досках
- Drag & Drop: Простое распределение промптов по доскам
- Экспорт: TXT (по отдельности или все), PDF и портативный JSON
- Интеграция с буфером: Режимы копирования (заголовок, текст, результат, всё)
- Темная тема: Современный эргономичный интерфейс
- Offline-First: Все данные сохраняются локально в JSON-файлах

ДЛЯ КОГО:
Для специалистов, работающих с ИИ, которым требуется надежное, конфиденциальное и удобное хранение промптов без облачной привязки.
