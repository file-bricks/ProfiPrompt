# ProfiPrompt — Microsoft Store Listing (简体中文)

## 应用名称
ProfiPrompt

## 简短描述 (最多 100 个字符)
AI提示词管理器：创建、版本化、在看板中整理并导出您的提示词。

## 详细描述

ProfiPrompt 是一款用于专业管理、版本控制与整理 AI 提示词的本地桌面工具。

功能特性：
- 提示词管理：树状层级创建、编辑与分类
- 版本控制：完整保存每次修改的历史记录
- 看板系统：主题面板与卡片式视图
- 拖拽整理：快速将提示词关联至对应看板
- 导出支持：TXT（单个或全部）、PDF 及便携式 JSON
- 剪贴板集成：灵活的复制模式（标题、正文、结果、全部）
- 深色模式：现代优雅的视觉设计
- 本地优先：所有数据以 JSON 格式存储于本地磁盘

适用对象：
经常使用人工智能工具并希望系统化整理、版本化管理及快速复用提示词的开发者、创作者及团队。
